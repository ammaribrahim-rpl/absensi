================================================================================
                    FOLDER AUDIO NOTIFIKASI ABSENSI
================================================================================

Folder ini berisi file audio/suara notifikasi yang digunakan pada aplikasi.

--------------------------------------------------------------------------------
FILE SUARA YANG TERSEDIA (SUDAH DIISI & SIAP DIGUNAKAN):
--------------------------------------------------------------------------------

1. terlambat.wav / terlambat.m4a / terlambat.mp3
   - Nada Chime Peringatan Tegas (Descend Alert Chime: D5 -> A4 -> F4)
   - Digunakan saat:
     a. Karyawan melakukan "Absen Masuk" lewat dari jam batas masuk (08:00 WIB).
     b. Karyawan melakukan "Selesai Istirahat" melebihi durasi batas 1 jam (60 menit).
     c. Waktu istirahat habis (countdown mencapai 00:00).
     d. Mendapatkan notifikasi peringatan keterlambatan baru.

2. sisa_5menit.wav / sisa_5menit.m4a / sisa_5menit.mp3
   - Nada Chime Pengingat Ramah (Ascend Chime: C5 -> E5 -> G5 -> C6)
   - Digunakan saat:
     Waktu istirahat karyawan tersisa 5 menit lagi (countdown mencapai 05:00).

--------------------------------------------------------------------------------
KUSTOMISASI:
--------------------------------------------------------------------------------
- File suara berkualitas studio sudah dibuat dan langsung aktif digunakan.
- Jika Anda ingin menggantinya dengan suara sendiri di masa mendatang, cukup
  timpa (replace) file di atas dengan file audio Anda.
- Format yang didukung: .wav, .m4a, .mp3, .ogg.
